# specdog

The spec genome platform. Ship with .dog files.

## Install

```bash
npm install -g dotdog
dotdog validate
```

## Format

- `.dog` — human-written spec genome (markdown + YAML). Free forever.
- `.dag` — machine-compiled graph (JSON). Enterprise.
