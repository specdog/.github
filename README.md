# specdog

The spec genome platform. Feed the dog. Ship with specs.

## Install

```bash
npm install -g dotdog
dotdog validate
```

## Format

- `.dog` — human-written spec genome. Free forever.
- `.dag` — machine-compiled graph. Enterprise.
