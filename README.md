# specdog

> **Feed the dog. Ship with specs.** CLI tool for structured software specs.

## Install

```bash
npm install -g dotdog
dotdog validate
```

## Format

- `.dog` — human-written spec genome. Free forever.
- `.dag` — machine-compiled graph. Token-efficient for AI agents.
